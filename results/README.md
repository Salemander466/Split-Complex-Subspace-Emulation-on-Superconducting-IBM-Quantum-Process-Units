# Results and Report Artifacts

This directory contains the machine-readable result ledgers for the split-complex QPU validation suite.

## Files

- `phase_test_results.json`: chronological phase-to-test mapping with backend, result, interpretation, and caveat.
- `theory_mapping_with_apa7_and_bibtex.json`: supported and challenged theory map with APA7 and BibTeX references.
- `conceptual_phase_mapping.json`: merged phase/test/theory map linking each experiment to conceptual implications.
- `validation_results.json`: compact validation result ledger used by the repository documentation.

## Scientific Position

These artifacts document reproducible QPU-executable split-complex subspace emulation behavior. They do not claim proof of new physics, formal quantum error correction replacement, physical pulse compression, or formal cryptographic security.
