# Contributing

Contributions must preserve reproducibility. New hardware experiments should include:

- Backend name
- Date and time of execution
- Shots
- Raw counts
- Target state
- Fidelity calculation
- Post-transpile `count_ops()`
- Compiled depth
- Circuit size
- Scheduled duration if available
- Qiskit and qiskit-ibm-runtime versions

Do not add claims of physical QEC replacement, physical pulse compression, new physics, or cryptographic security unless independently verified and supported by the measurement protocol.
